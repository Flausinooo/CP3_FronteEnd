# 🎮 Loja Gamer – GameZone

Projeto desenvolvido para a CP3 da FIAP na disciplina de Front-End.

## 📌 Sobre

A **GameZone** é uma loja gamer criada para apresentar produtos e promoções voltadas ao público gamer.

O projeto possui páginas de navegação, cards com produtos, promoções, formulário de contato e foi desenvolvido usando HTML, CSS e JavaScript.

---

## 🚀 Tecnologias usadas

- HTML5
- CSS3
- JavaScript
- VS Code
- Git e GitHub
